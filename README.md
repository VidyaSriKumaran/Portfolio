# Vidya Sri AK — Portfolio

A responsive developer portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Extract this ZIP.
2. Open the `VidyaSri_Portfolio` folder.
3. Double-click `index.html` to open it in your browser.

You can also open the folder in VS Code and use the Live Server extension.

## Files
- `index.html` — portfolio content and sections
- `style.css` — layout, responsive design, colors and animations
- `script.js` — mobile navigation, reveal animations and certificate preview
- `images/` — supplied profile photo and certificate images

## Update before publishing
- Review every section and make sure the project descriptions match your final work.
- Add a resume link if you want your resume downloadable from the portfolio.
- The College Management System GitHub link and Recipe Management Website live link are included.
- The EV Charging Stations entry is intentionally brief; add its final description and repository/demo link when ready.

## Publish with GitHub Pages
1. Create or open your portfolio repository on GitHub.
2. Upload the contents of this folder (keep `index.html` at the repository root).
3. In repository Settings → Pages, choose the deployment branch and root folder.
4. Save and wait for GitHub Pages to publish.
